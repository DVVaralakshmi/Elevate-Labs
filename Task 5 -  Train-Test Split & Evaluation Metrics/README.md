# 📌 AI & ML Internship  
## 📊 Task 5 – Train-Test Split & Model Evaluation  

---

## 🔍 Objective  

The objective of this task is to split the dataset into training and testing sets,  
train a Machine Learning model, and evaluate its performance using standard evaluation metrics.

This task helps in understanding how models are trained, tested, and interpreted to ensure they generalize well on unseen data.

> 💡 **“Evaluation on unseen data is the true measure of a model’s performance.”**

---

## 🛠 Tools & Technologies Used  

- Python   
- Scikit-learn  
- Jupyter Notebook / Google Colab  

---

## 📂 Dataset Used  

### ❤️ Heart Disease Dataset  

This dataset contains medical attributes used to predict the presence of heart disease.

**Key features include:**
- Age  
- Sex  
- Chest pain type  
- Resting blood pressure  
- Cholesterol  
- Maximum heart rate  
- Target (**0 = No disease, 1 = Disease**)  

The dataset is suitable for **binary classification problems**.

---

## 🧭 Task Activities Performed  

### 🔀 1️⃣ Split Dataset into Train and Test Sets  

- Used `train_test_split()` from Scikit-learn  
- Training data used for learning  
- Testing data used for evaluation  

---

### 📘 2️⃣ Purpose of Training vs Testing  

- **Training set:** Helps the model learn patterns  
- **Testing set:** Evaluates performance on unseen data  
- Prevents overfitting and biased results  

---

### 🤖 3️⃣ Model Training (Logistic Regression)  

- Trained a **Logistic Regression** model  
- Selected due to suitability for binary classification  

---

### 📊 4️⃣ Prediction on Test Data  

- Generated predictions using the trained model  
- Compared predicted values with actual labels  

---

### 📈 5️⃣ Evaluation Metrics  

Calculated the following metrics:

- **Accuracy** – Overall correctness  
- **Precision** – Correct positive predictions  
- **Recall** – Ability to identify actual positives  

---

### 🧮 6️⃣ Confusion Matrix  

- Generated confusion matrix  
- Explained:  
  - True Positives  
  - True Negatives  
  - False Positives  
  - False Negatives  
- Visualized using a heatmap  

---

### 🧠 7️⃣ Interpretation of Results  

- Interpreted accuracy, precision, and recall values  
- Evaluated model effectiveness  
- Identified Logistic Regression as a good baseline model  

---

## ⚠️ Why Train-Test Split & Evaluation Are Important  

- Prevents overfitting  
- Ensures model generalization  
- Provides reliable performance estimation  
- Helps compare different Machine Learning models
