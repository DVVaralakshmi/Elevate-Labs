# 📌 AI & ML Internship  
## 📊 Task 3 – Exploratory Data Analysis (EDA)  

---

## 🔍 Objective  
The objective of this task is to **perform Exploratory Data Analysis (EDA)** on datasets to understand  
**data distribution, patterns, relationships, and outliers** using visualizations.

EDA helps in gaining insights that guide **feature selection and model building**.

> 💡 “Good insights come from good data exploration.”

---

## 🛠 Tools & Technologies Used  

- Python  
  - NumPy  
  - Matplotlib  
  - Seaborn  
- Tableau Public  

---

## 📂 Datasets Used  

### 🎬 Dataset 1: Netflix Movies & TV Shows Dataset  
This dataset contains information about Netflix content such as:
- Type (Movie / TV Show)  
- Country  
- Release year  
- Rating  
- Duration  

It is mainly used to analyze **categorical distributions and content trends**.

---

### 🌸 Dataset 2: Iris Dataset  
This dataset contains flower measurements such as:
- Sepal length  
- Sepal width  
- Petal length  
- Petal width  
- Species  

It is widely used for **classification and feature relationship analysis**.

---

## 🧭 Task Activities Performed  

### 📊 1️⃣ Distribution Analysis  
- Used **histograms** to analyze numerical feature distributions  
- Helped understand data spread and skewness  

---

### 📋 2️⃣ Categorical Data Analysis  
- Used **count plots** to analyze categorical features  
- Identified dominant categories and class balance  

---

### 📦 3️⃣ Outlier Detection  
- Used **box plots** to detect outliers in numerical features  
- Helped identify extreme values affecting data quality  

---

### 🔗 4️⃣ Correlation Analysis  
- Used **correlation heatmaps**  
- Identified relationships between numerical features  

---

### 🧠 5️⃣ Insight Extraction  
- Analyzed visualizations to identify important patterns  
- Understood feature importance and data behavior  

---

## ⚠️ Why Exploratory Data Analysis is Important  

- Helps understand dataset structure  
- Detects outliers and anomalies  
- Identifies feature relationships  
- Guides preprocessing and model selection
