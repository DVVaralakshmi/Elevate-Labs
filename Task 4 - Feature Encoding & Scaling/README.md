## 📊 Task 4 – Feature Encoding & Scaling  

---

## 🔍 Objective  
The objective of this task is to **perform feature engineering** by applying  
**encoding techniques for categorical data** and **scaling techniques for numerical data**.

This task prepares datasets for **Machine Learning algorithms**.

---

## 🛠 Tools & Technologies Used  

- Python (Pandas, NumPy, Scikit-learn)  
- Jupyter Notebook / Google Colab  

---

## 📂 Dataset Used  

### 💼 Adult Income Dataset  
Demographic and employment data used for **classification** tasks.

---

## 🧭 Task Activities Performed  

1. Identified categorical and numerical features  
2. Applied Label Encoding  
3. Applied One-Hot Encoding  
4. Applied StandardScaler  
5. Saved processed dataset  

---

## ⚠️ Why Feature Encoding & Scaling is Important  

- Machine Learning models cannot work with categorical text data  
- Feature scaling ensures all numerical features are on the same scale  
- Distance-based algorithms depend heavily on scaled features
